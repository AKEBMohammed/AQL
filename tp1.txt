Partie 1: Introduction à Docker
1.1 Qu'est-ce que Docker?
Docker est une plateforme de virtualisation légère qui permet d'exécuter des
applications dans des conteneurs isolés. Les conteneurs Docker sont autonomes et
regroupent tout le nécessaire pour exécuter une application, y compris son code, ses
dépendances, son système d'exploitation et ses configurations.
1.2 Images Docker
Une image Docker est un modèle réutilisable à partir duquel des conteneurs sont
créés. Elle contient l'ensemble des instructions nécessaires pour configurer et exécuter
2
une application. Les images Docker peuvent être stockées localement sur votre
machine ou dans des registres publics comme Docker Hub.
1.3 Conteneurs Docker
Un conteneur Docker est une instance exécutable d'une image Docker. Il s'agit d'un
environnement isolé qui encapsule l'application et ses dépendances. Les conteneurs
Docker sont légers, portables et peuvent être démarrés, arrêtés et déplacés facilement.
1.4 Registres Docker
Un registre Docker est un référentiel centralisé pour stocker et partager des images
Docker. Le registre Docker public le plus connu est Docker Hub, mais il existe
également des registres privés pour les organisations et les entreprises.
1.5 Docker Compose
Docker Compose est un outil permettant de définir et d'exécuter des applications
multi-conteneurs. Il simplifie la gestion de plusieurs conteneurs interdépendants en
regroupant les configurations dans un seul fichier YAML.
Partie 2: Tests d'intégration Java avec Testcontainers
2.1 Qu'est-ce que Testcontainers?
Testcontainers est une bibliothèque Java open source qui facilite l'exécution de tests
d'intégration dans des conteneurs Docker. Elle permet de démarrer et d'arrêter
automatiquement des conteneurs pour les bases de données, les navigateurs web et
autres services requis par des tests.
2.2 Avantages de l'utilisation de Testcontainers
L'utilisation de Testcontainers pour les tests d'intégration Java présente plusieurs
avantages:
 Environnement de test isolé: Chaque test s'exécute dans son propre conteneur,
garantissant une isolation et une reproductibilité des tests.
 Démarrage et arrêt automatiques des conteneurs: Testcontainers gère
automatiquement le cycle de vie des conteneurs, simplifiant la configuration et
l'exécution des tests.
 Accès facile aux services requis: Testcontainers fournit des API simples pour
interagir avec les services exécutés dans les conteneurs, tels que les bases de
données et les navigateurs web.

2.3 Exemple de test d'intégration avec TestContainers
Considérons une application web simple qui gère une liste de tâches. L'application
utilise une base de données MySQL pour stocker les tâches. Nous allons écrire un test
d'intégration pour vérifier que l'application peut créer, récupérer et supprimer des
tâches.
Prérequis
 Avoir un projet Spring Boot avec une application web et une connexion à une
base de données MySQL configurée.
 Avoir Testcontainers installé dans votre projet.
On commence par l'installation de Testcontainers dans le projet Java. Elle dépend de
l'outil de build que vous utilisez. Voici les instructions pour les deux outils les plus
courants :
Installation avec Maven
1. Ajoutez la dépendance Testcontainers à votre fichier pom.xml:
<dependency>
<groupId>org.testcontainers</groupId>
<artifactId>testcontainers</artifactId>
<version>latest.stable</version>
<scope>test</scope>
</dependency>
2. Ajoutez la dépendance du driver de base de données que vous souhaitez
utiliser avec Testcontainers (par exemple, pour MySQL):
<dependency>
<groupId>mysql</groupId>
<artifactId>mysql-connector-java</artifactId>
<version>8.0.30</version>
<scope>test</scope>
</dependency>
Installation avec Gradle
1. Ajoutez la dépendance Testcontainers à votre fichier build.gradle:
testCompile 'org.testcontainers:testcontainers:latest.stable'
testCompile 'mysql:mysql-connector-java:8.0.30'

Une fois que vous avez ajouté les dépendances nécessaires, vous pouvez commencer
à utiliser Testcontainers dans vos classes de test JUnit. Référez-vous à la

Étapes de test :
1. Créer une classe de test: Créez une classe de test annotée avec
@RunWith(Junit5.class). Cette classe contiendra vos tests d'intégration.
@RunWith(JUnit5.class)
public class TaskControllerIntegrationTest {
// ...
}
2. Définir le conteneur MySQL avec Testcontainers: Utilisez Testcontainers pour
démarrer un conteneur MySQL et le mapper à un port local.
@Rule
public KGenericContainer<MySqlContainer> mysql =
KGenericContainer.dockerized(MySqlContainer.class)
.withUsername("root")
.withPassword("password")
.withDatabaseName("testdb");
3. Injecter les dépendances: Injectez les dépendances nécessaires dans votre
classe de test, telles que le service de tâches et le port du conteneur MySQL.
@Autowired
private TaskService taskService;
@TestPropertySource(properties = {
"spring.datasource.url=jdbc:mysql://localhost:${test.container.mysql.firstM
appedPort}/testdb",
"spring.datasource.username=root",
"spring.datasource.password=password"
})
4. Écrire les tests d'intégration: Créez des méthodes de test pour vérifier les
différentes fonctionnalités de l'application web, telles que la création, la
récupération et la suppression de tâches.
@Test
public void testCreateTask() {
// Créer une nouvelle tâche
Task task = new Task("Tâche 1", "Description de la tâche 1");
// Enregistrer la tâche
taskService.saveTask(task);
// Vérifier que la tâche a été enregistrée dans la base de données
Long taskId = task.getId();
Optional<Task> retrievedTask = taskService.findTaskById(taskId);

assertTrue(retrievedTask.isPresent());
assertEquals(task, retrievedTask.get());
}
@Test
public void testGetTask() {
// Créer une tâche et l'enregistrer dans la base de données
Task task = createAndSaveTask();
// Récupérer la tâche par son ID
Long taskId = task.getId();
Optional<Task> retrievedTask = taskService.findTaskById(taskId);
assertTrue(retrievedTask.isPresent());
assertEquals(task, retrievedTask.get());
}
@Test
public void testDeleteTask() {
// Créer une tâche et l'enregistrer dans la base de données
Task task = createAndSaveTask();
// Supprimer la tâche par son ID
Long taskId = task.getId();
taskService.deleteTaskById(taskId);
// Vérifier que la tâche a été supprimée de la base de données
Optional<Task> retrievedTask = taskService.findTaskById(taskId);
assertFalse(retrievedTask.isPresent());
}
private Task createAndSaveTask() {
// Créer une nouvelle tâche
Task task = new Task("Tâche 1", "Description de la tâche 1");
// Enregistrer la tâche
taskService.saveTask(task);
return task;
}
